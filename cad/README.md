# cad/

| Folder | What |
|---|---|
| `practice/` | Ring 0 parts: rim (Revolve), bracket (Extrude, Cut, Hole Wizard), wing element, mini weldment frame. Nothing is throwaway; the rim and wing element get reused. |
| `airfoils/` | Coordinate files generated by `matlab/cad/make_airfoils.m` (`.dat` normalized, `.sldcrv` in mm). |
| `macros/` | VBA macros as `.bas` text: import airfoil, export configurations to STEP, save standard views. Untested until SolidWorks runs them. |
| `generate/` | Python build123d generator (`build_parts.py`) that builds the wheels, wings, endplates, floor, nose and sidepods from the parameter file. |
| `step/` | The 18 STEP bodies it writes, in car coordinates, for import or as a size check against the native parts. Not opened in SolidWorks yet. |
| `generate/` | Python build123d generator (`build_parts.py`) that builds the wheels, wings, endplates, floor, nose and sidepods from the parameter file. |
| `step/` | The 18 STEP bodies it writes, in car coordinates, for import or as a size check against the native parts. Not opened in SolidWorks yet. |
| `layout/` | Ring 2a master layout part (hardpoints, planes, driver envelope) driven by `params/car_params.txt`. |
| `chassis/`, `suspension/`, `body/`, `aero/`, `cfd_body/` | Ring 2b to 2f parts and sub-assemblies. |
| `formula_single_seater.SLDASM` | The top-level assembly (Ring 2). |

Native SolidWorks files are tracked with git LFS (`.gitattributes`). Set up once:

```bash
git lfs install
```

Linking the parameter file: in any part, Tools > Equations > tick "Link to external file", choose `params/car_params.txt`. Use the global variables in sketch dimensions as `="wheelbase"` etc. The same file is read by MATLAB, so a value changed here moves the lap sim too.
