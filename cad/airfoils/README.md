# Airfoil coordinate files

Generated by `matlab/cad/make_airfoils.m` from the NACA 4-digit closed form. Chords come from `params/car_params.txt`.

| File | Section | Nominal chord (mm) | Use |
|---|---|---|---|
| fw_main.dat / .sldcrv | NACA 6412 | 400 | front wing main element, 6% camber at 40% chord, 12% thick |
| fw_flap1.dat / .sldcrv | NACA 8410 | 220 | front wing first flap, 8% camber, 10% thick |
| fw_flap2.dat / .sldcrv | NACA 9409 | 160 | front wing second flap, 9% camber, 9% thick |
| rw_main.dat / .sldcrv | NACA 6414 | 450 | rear wing main element, 6% camber, 14% thick (holds the spar) |
| rw_flap1.dat / .sldcrv | NACA 8410 | 240 | rear wing first flap |
| rw_flap2.dat / .sldcrv | NACA 9409 | 170 | rear wing second flap |
| symmetric.dat / .sldcrv | NACA 0012 | 300 | reference section for the CFD smoke test and endplate leading edge |

`.dat` is normalized (x/c, y/c, Selig order) and is what `cad/macros/ImportAirfoil.bas` reads. `.sldcrv` is the same curve in mm at the nominal chord for manual import with Insert > Curve > Curve Through XYZ Points.

To use a tabulated high-lift section instead (for example S1223), save its coordinates in the same two-column Selig format as `cad/airfoils/<name>.dat`; the macro does not care which section it is.
