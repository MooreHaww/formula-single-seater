# 06 Importing an airfoil and extruding a wing element (45 min)

Goal: a 500 mm span NACA 0012 element at 300 mm chord from `cad/airfoils/symmetric.sldcrv`, with a hand-checked mass. The same element is the geometry for the CFD smoke test in `cfd/ansys_quickstart.md`, so save it where that file expects: `cad/practice/wing_element.SLDPRT`.

Two ways to get the curve in: by hand through Curve Through XYZ Points (this exercise; always works), or with the `ImportAirfoil` macro (exercise 8; untested). Learn the manual way first.

## About the files

`cad/airfoils/symmetric.sldcrv` is a text file with three columns `x y z` in mm, one point per line, going round the section from the trailing edge over the top to the leading edge and back under (Selig order), at a chord of 300 mm; z is 0 on every line. `symmetric.dat` is the same section normalised to a chord of 1 (x/c, y/c), which the macro reads. Both were generated by `matlab/cad/make_airfoils.m`; the README there lists the sections.

## Steps

1. New part from `cad/templates/car_part.prtdot` (exercise 5), or a plain MMGS part if you have not made the template. Save as `cad/practice/wing_element.SLDPRT`.
2. **Insert > Curve > Curve Through XYZ Points** (**verify**: in 2026 it may sit under Features > Curves > Curve Through XYZ Points; the search box finds it as "Curve Through XYZ Points"). A table dialog opens. Click **Browse**, set the file type to Curve files (*.sldcrv) or Text (*.txt), pick `cad/airfoils/symmetric.sldcrv`. The table fills with 159 rows (tab separated). Scroll: x runs from 300 (TE) down to 0 (LE) and back to 300; y goes up to +18.0 (at x = 94.7) and down to -18.0; z is 0 throughout. The first and last rows are both (300, 0, 0): the section is closed. If the tool refuses a curve whose ends coincide ("Unable to create curve", **verify**), delete the last row in the table and OK again; the sketch closes the 0.1 mm gap in step 4.
3. The curve appears in the **XY plane of the part**, which is the Front plane (`FRONT_AXLE` if you used the template). In the car frame that is the plane normal to X, which is **not** where a wing section belongs (a wing section lies in the XZ plane, normal to Y, and is extruded along Y, the span). For the practice element it does not matter; for the real wings `docs/cad_playbook/10_front_wing.md` moves the body afterwards or uses the `.sldcrv` with Y and Z columns swapped (**verify** which the playbook chose). Rename the curve `Curve_naca0012_c300`.
4. Sketch on the same plane (Front / FRONT_AXLE). Ctrl+8. Click the curve in the graphics area, then Sketch > **Convert Entities**: the curve becomes a spline in the sketch, black (it is tied to the curve, "On Edge" relations). If you deleted the last row, close the trailing edge with a short Line from the upper TE point to the lower TE point; if the curve came in closed, the sketch is already one loop. Exit the sketch. Rename `Sketch_section`.
5. Features > **Extruded Boss/Base**, Direction 1 Blind, `500`, or better **Mid Plane** `500` so the element is centred on the plane (the CFD domain is then symmetric). Tick. Rename `Extrude_element`.
6. Material: Material > Edit Material > at the bottom, **Custom Materials** > right-click > New Category "car", New Material "carbon_sandwich": Density **1600** kg/m3, Elastic modulus 60,000 MPa, Poisson 0.3 (the playbook's carbon stand-in). Apply. **verify** the custom-material right-click path in 2026 (it may be a "+" button).
7. Tools > Evaluate > **Check**: one body, no open edges.
8. Ctrl+S. Then File > Save As > type **STEP AP214 (*.step)** > `cfd/geometry/wing_element_naca0012.STEP` (make the folder if it is not there; the folder is git-LFS tracked). Options > tick "Solid/Surface geometry", untick curves. This is the file the CFD smoke test imports.

## Expected result

A straight 500 mm span, 300 mm chord, 36 mm thick symmetric element.

Hand mass: the area of a NACA 00xx section is 0.6851 x (t/c) x c^2 (from integrating the 4-digit thickness polynomial); for 12 % at 300 mm that is 0.6851 x 0.12 x 90,000 = 7,399 mm^2. Volume 7,399 x 500 = 3.70e6 mm^3. At 1600 kg/m3: **5.92 kg** (solid; the real elements are hollow, this is a block for practice and CFD).

## Check

- Mass Properties: 5.90 to 5.95 kg (the tabulated curve is a polygon of 120 points, slightly under the exact area).
- Measure: chord 300.00 (LE point to TE line), max thickness 36.0 at x = 90 (30 % chord): Section View on the Front plane and Measure between the top and bottom spline points near x = 90, or trust the Mass Properties.
- The STEP file opens back in SolidWorks (File > Open, STEP, Import as solid) as one solid.

## Pitfalls

- Importing `.dat` (x/c from 0 to 1) through Curve Through XYZ Points gives a 1 mm chord element; use the `.sldcrv` (mm) for manual import, the `.dat` is for the macro, which scales it.
- The `.sldcrv` ends on the point it started from. Some releases accept that and make a closed curve, others say "Unable to create curve" (**verify**): drop the last row in the table rather than editing the file (the macro's reader opens the TE by 0.0005 chord for the same reason).
- Convert Entities on a curve makes a spline tied to the curve: edit the curve file and the sketch follows; delete the curve and the sketch breaks (dangling relations, yellow). Keep the curve feature above the sketch in the tree.
